# D'Barros Barbearia

Site de agendamento da D'Barros Barbearia integrado ao Supabase.

## Arquivos

- `index.html` — site principal
- `vercel.json` — configuração simples para publicação na Vercel

## Publicação

1. Envie estes arquivos para um repositório no GitHub.
2. Importe o repositório na Vercel.
3. Framework Preset: `Other`.
4. Build Command: deixar vazio.
5. Output Directory: deixar vazio.
6. Deploy.
